# Thai Voice Lab

เว็บและ AI skill สำหรับสร้างเสียงภาษาไทยด้วย **VoxCPM2 บนคอมพิวเตอร์ของคุณ** ใช้กับ Codex หรือ Claude Code ได้ มีเสียงตัวอย่างไทย CC0 8 เสียง อัปโหลดเสียงอ้างอิง ปรับความเร็ว ฟังผลลัพธ์ และดาวน์โหลด WAV

การติดตั้งมี 2 ส่วน: **โปรแกรม + โมเดลที่รันบนเครื่องลูกค้า** และ **สกิลที่บอก AI วิธีเรียกโปรแกรมนั้น** การลงสกิลอย่างเดียวไม่ทำให้มีโมเดลพร้อมใช้

## สำหรับลูกค้า: สั่ง AI ให้ติดตั้ง

เปิด Codex หรือ Claude Code แบบที่เข้าถึงไฟล์และเทอร์มินัลบนเครื่องของคุณ แล้ววางข้อความด้านล่าง แชตเว็บทั่วไปที่ไม่มีสิทธิ์เข้าถึงเครื่องจะติดตั้งหรือเรียก localhost ให้ไม่ได้

## ติดตั้งเอง

### สิ่งที่ต้องมี

- Python **3.11–3.13** (แนะนำ 3.12), Git และ `ffmpeg` ใน PATH
- อินเทอร์เน็ตสำหรับติดตั้งแพ็กเกจและดาวน์โหลดโมเดลครั้งแรกหลาย GB หลังติดตั้งแล้ว การสร้างเสียงใช้ไฟล์ในเครื่อง
- พื้นที่ว่างสำหรับ Python dependencies, โมเดล และไฟล์เสียง แนะนำเผื่ออย่างน้อย 15 GB; RAM/VRAM ที่เพียงพอกับโมเดล 2B โดยความเร็วขึ้นกับเครื่อง
- ทดสอบการสร้างเสียงจริงบน macOS / Apple Silicon แล้ว ตัว launcher รองรับ Windows/Linux ด้วย แต่ยังไม่ได้ทดสอบฮาร์ดแวร์ทุกแบบ

macOS ที่มี Homebrew: `brew install python@3.12 git ffmpeg` และใช้ `python3.12` ในคำสั่งติดตั้ง หาก `python3` ชี้ไปยังรุ่นอื่น

Ubuntu/Debian: ติดตั้ง Python รุ่นที่รองรับ, `python3-venv`, Git และ ffmpeg ผ่าน package manager ของระบบ Windows: ติดตั้ง Python รุ่นที่รองรับ, Git และ ffmpeg แล้วเปิดเทอร์มินัลใหม่ให้ PATH มีคำสั่งเหล่านี้ ใช้ `py -3.12` แทน `python3` ได้

### ดาวน์โหลดและตั้งค่า

```sh
git clone https://github.com/phawitb/th-voice-lab.git
cd th-voice-lab
python3 scripts/setup.py --target codex --download-model
```

เปลี่ยน `codex` เป็น `claude` หรือ `both` ได้ หากใช้เฉพาะเว็บ ให้เลือก `none`

ตัวติดตั้งจะ:

1. สร้าง `.venv` ในโปรเจกต์และติดตั้ง dependencies โดยไม่แก้ Python หลัก
2. ตรวจการ import โมเดลและอุปกรณ์ประมวลผล
3. ดาวน์โหลด VoxCPM2 รุ่นที่กำหนดไว้ โดยใช้ cache เดิมเมื่อมี
4. เตรียมเสียง CC0 8 เสียงจากไฟล์ที่รวมไว้ในรีโป
5. บันทึกการตั้งค่าเฉพาะเครื่องใน `.runtime.json` และลงสกิลสำหรับ AI ที่เลือก

หากพบ `.venv` หรือสกิลที่ไม่ได้สร้างโดยตัวติดตั้ง จะเก็บของเดิมและแจ้งให้ตรวจสอบก่อน ไม่ลบหรือเขียนทับอัตโนมัติ รันซ้ำหลังแก้ปัญหาได้ สกิลที่ตั้งค่าไว้กับ checkout เดียวกันจะถูกเก็บไว้

ดูแผนก่อนติดตั้งโดยไม่เปลี่ยนไฟล์: `python3 scripts/setup.py --target codex --download-model --plan`

สำหรับผู้ที่มี Python environment พร้อม VoxCPM2 แล้ว:

```sh
python3 scripts/setup.py --target codex --reuse-python /absolute/path/to/python --download-model
```

โหมดนี้ตรวจสอบและใช้ environment เดิม ไม่ติดตั้งแพ็กเกจเพิ่มเข้าไป

### เปิดเว็บ

```sh
python3 scripts/start_server.py
```

หรือใช้ `./start.sh` บน macOS/Linux เปิด **http://127.0.0.1:7860** และปล่อยเทอร์มินัลนี้ทำงานไว้ ปิดด้วย `Ctrl C` งานที่กำลังสร้างจะจบก่อนปิดแบบปกติ

ตัว launcher เลือก `THAI_VOICE_PYTHON`, การตั้งค่าใน `.runtime.json`, `.venv`, Miniforge ที่มีอยู่ หรือ Python ปัจจุบันตามลำดับ เปลี่ยนพอร์ตด้วย `PORT`; ใช้ `THAI_VOICE_MODEL` ระบุโฟลเดอร์โมเดลเองได้

## ใช้สกิลหลังติดตั้ง

- **Codex:** สกิลอยู่ที่ `~/.agents/skills/thai-voice-lab` เรียกด้วย `$thai-voice-lab`
- **Claude Code:** สกิลอยู่ที่ `~/.claude/skills/thai-voice-lab` เรียกด้วย `/thai-voice-lab`
- หากยังไม่พบสกิล ให้เปิดเซสชันใหม่ ตัวสกิลใช้ server เดิม และเริ่ม server ที่ตั้งค่าไว้ได้เมื่อยังไม่เปิด

ตัวอย่าง Codex:

> ใช้ $thai-voice-lab สร้างเสียงข้อความ “ยินดีต้อนรับเข้าสู่ thai voice lab สร้างเสียงได้ฟรี ไม่จำกัด บนคอมพิวเตอร์เราเอง” ด้วยเสียงไทย 01 บันทึกเป็น welcome.wav แล้วส่งไฟล์ให้ฟัง

ตัวอย่าง Claude Code:

> /thai-voice-lab อ่าน script.txt ด้วยเสียงไทย 02 ความเร็ว 0.95 บันทึกเป็น narration.wav และรอจนเสร็จ

ใช้เสียงของตัวเอง:

> ใช้ skill thai-voice-lab สร้างเสียงจาก script.txt โดยใช้ my-voice.wav ที่ฉันมีสิทธิ์ใช้เป็นเสียงอ้างอิง บันทึกเป็น my-narration.wav

ตัวสกิลบันทึกหมายเลขงานใน `<ชื่อไฟล์>.job.json` หากหมดเวลารอ ให้สั่งรอรับงานเดิมต่อ ไม่สร้างใหม่โดยอัตโนมัติ รายละเอียด: [คู่มือสกิล](skills/thai-voice-lab/references/installation.md)

หน้า **ใช้กับ AI** ในเว็บมีคำสั่งติดตั้งสำหรับลูกค้าใหม่ ตัวอย่างพร้อมคัดลอก และ ZIP ดาวน์โหลด ZIP นี้มีเฉพาะสกิลกับตัวช่วยลงสกิล ไม่รวมแอปหรือโมเดล; ลูกค้าใหม่ควรเริ่มจากคำสั่งติดตั้ง GitHub ด้านบน

## การใช้งานและข้อมูลในเครื่อง

- ข้อความ 1–2,000 ตัวอักษรต่อครั้ง สร้างได้ไม่จำกัดจำนวนครั้ง มีคิวได้ไม่เกิน 3 งานและสร้างทีละงาน
- อัปโหลด WAV, MP3, M4A, FLAC, OGG, WebM ขนาดไม่เกิน 20 MB ยาว 3–30 วินาที ใช้ 12 วินาทีแรกเป็นเสียงอ้างอิง ควรเป็นเสียงพูดคนเดียว ไม่มีดนตรี
- ไฟล์อัปโหลดอยู่ใน `data/uploads/`; WAV ที่สร้างใน `data/outputs/`; ประวัติใน `data/jobs/`
- ทุกอย่างใน `data/`, `.runtime.json`, และ `local.json` ของสกิลถูกกันออกจาก Git
- เซิร์ฟเวอร์รับเฉพาะ loopback ไม่มีระบบบัญชีสำหรับเปิดให้คนอื่นใช้ผ่านอินเทอร์เน็ต
- ครั้งแรกใช้เวลาโหลดโมเดลเข้า RAM ผลลัพธ์อาจออกเสียงบางคำไม่ถูกหรือขาดช่วง ควรฟังก่อนนำไปใช้
- โมเดลรันในเครื่อง ไม่ใช้ paid TTS API แต่ค่าบริการของ Codex/Claude เป็นไปตามแพ็กเกจ AI ที่ลูกค้าใช้

## สิทธิ์ใช้งานและการแจกจ่าย

VoxCPM2 ระบุ [Apache 2.0 และอนุญาตเชิงพาณิชย์](https://huggingface.co/openbmb/VoxCPM2) ตัวโมเดลดาวน์โหลดจากผู้พัฒนา ไม่ได้รวม weights ในรีโปนี้

เสียงตัวอย่าง 8 เสียงเป็น CC0 ตาม [Common Voice 17.0 public mirror](https://huggingface.co/datasets/fsicoli/common_voice_17_0) รายชื่อคลิป ข้อความ ที่มา และ SHA-256 อยู่ใน [manifest](assets/voices/manifest.json) อ่านรายละเอียดใน [เครดิตเสียง](assets/voices/README.md) CC0 ไม่ให้สิทธิ์แอบอ้างหรือรับรองแทนเจ้าของเสียง สิทธิ์เสียงอัปโหลดของลูกค้าต้องตรวจแยกกัน

รีโปนี้ไม่รวมเสียงส่วนตัวของผู้พัฒนา ไฟล์ลูกค้า ประวัติงาน หรือระบบตรวจสอบการซื้อ/คีย์ไลเซนส์ เงื่อนไขขายสกิลและบริการสนับสนุนเป็นข้อตกลงแยกกับผู้ขาย ไม่เปลี่ยนสัญญาอนุญาตของโมเดลหรือเสียงต้นทาง

## สำหรับผู้พัฒนา

```sh
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q
node --check static/app.js
python3 scripts/package_skill.py
```

บน Windows ใช้ `.venv\Scripts\python.exe` แทน `.venv/bin/python` การทดสอบ API ใช้ตัวสร้างเสียงเบา; การยืนยันโมเดลจริงต้องทดสอบสร้างเสียงแยกต่างหาก

- `app.py` / `engine.py`: API, คิวงาน และ VoxCPM2
- `voice_catalog.py` / `assets/voices/`: เริ่มต้นคลังเสียงสาธารณะโดยเก็บข้อมูลเดิมของผู้ใช้
- `scripts/setup.py` / `scripts/start_server.py`: ติดตั้งและเปิด runtime ของลูกค้า
- `skills/thai-voice-lab/`: สกิลข้าม AI และ client แบบ standard library
- `static/`: เว็บ minimal โทนสว่าง ไม่ต้อง build หรือใช้ CDN
